Ganpati Bappa Invitation
=========================

The website includes hidden looping background music.

Music file:
assets/ganpati-music.mp3

IMPORTANT:
1. Replace the empty placeholder ganpati-music.mp3 with your own MP3.
2. Do not rename the file unless you also change the source path in index.html.
3. Music starts after the visitor's first click/tap/keyboard interaction because modern browsers block audible autoplay.
4. There is NO visible music control for visitors.
5. Developer settings are in script.js:
   const MUSIC_VOLUME = 0.35;

The rest of the website remains responsive and uses the Ganpati Bappa image.
